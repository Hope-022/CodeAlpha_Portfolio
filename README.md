## Features

- Sections for Home, About Me, Skills, Projects, Certifications and Contact
- Sticky navigation bar that stays visible while scrolling
- Smooth scrolling between sections
- Scroll-spy: the active nav link updates as you scroll (built with IntersectionObserver)
- Scroll-reveal fade-in animations, with a `prefers-reduced-motion` fallback for accessibility
- Hover effects on links, icons and buttons
- Fully responsive layout (desktop, tablet and mobile) with a hamburger menu on small screens
- Resume link that opens the PDF in a new tab
- Social and contact links (Email, LinkedIn, GitHub, X/Twitter, TikTok)
````
## Built with

- **HTML5**: semantic structure (`header`, `nav`, `main`, `section`, `article`)
- **CSS3**: custom properties (variables), Grid, Flexbox, media queries
- **JavaScript (ES6)**: mobile menu logic, IntersectionObserver for scroll-spy and reveal animations
- **Git & GitHub**: version control with milestone-based commits
- **Netlify**: deployment

## Running it locally

1. Clone the repository:
```bash
   git clone [https://github.com/Hope-022/CodeAlpha_Portfolio]
````
2. Open the folder and double-click `index.html`, or use the Live Server extension in VS Code.

No installation or build step is needed.
